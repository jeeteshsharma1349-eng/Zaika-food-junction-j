ZAiKA FOOD JUNCTION — MOBILE BILLING

This is a standalone phone-first billing website. It does not require Supabase, login, internet, or any online-order feature.

IMPORTANT FOR GITHUB:
Upload the CONTENTS of this folder to the repository root, not the ZIP itself and not a nested folder. Ensure index.html, app.js and style.css are visible at the top level.

Menu is preloaded on first opening. If an older empty version was already opened, this fixed version uses separate local storage keys (zaika_menu_v2 / zaika_bills_v2) so it will initialize the menu independently.

Features:
- Full menu preloaded from supplied menu list and price notes
- Category filters and search
- Add items and quantity +/- with automatic multiplication
- Discount, Cash / UPI / Card
- Daily sales, bill count, average bill
- Bill history, reprint and WhatsApp share
- Browser print dialog (choose thermal printer or A4)
- No GST, as requested

Data is stored in this phone's browser. Do not clear browser site data. This version does not sync between devices.

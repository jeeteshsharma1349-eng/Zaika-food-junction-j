# Zaika Food Junction – Mobile Billing

A phone-first billing app for use in the shop. No online ordering, customer login, delivery management, or cloud account.

## Features
- Fast item selection and search, category filters, quantity +/- and automatic totals
- Cash / UPI / Card payment entry; GST disabled
- Save bills on this phone, automatic bill numbering, daily bill count and daily sales total
- Bill history with reprint and WhatsApp share
- Thermal receipt or A4 printing through the Android print dialog
- Menu editor to update item names and prices

## Use on your Android phone
1. Host this folder as a static website (for example GitHub Pages) or open it through a local web server.
2. Open the website in Chrome on your phone.
3. Use Chrome menu → **Add to Home screen** for an app-like shortcut.
4. Bills and menu are saved in this phone's browser storage. Use the same browser and do not clear its site data.

## Printing and WhatsApp
- Tap **Save bill & print** to save and open the Android print flow. Select your thermal printer or A4 printer.
- Open **Bill history** and tap **WhatsApp** beside any bill to share the bill details. If a customer mobile number was entered, WhatsApp opens that chat; otherwise it opens the share flow.

## Important
This version stores data locally in the browser on this phone. It does not sync to another device and clearing browser site data can erase saved bills. Keep the phone/browser data intact. Verify menu prices before first use.
